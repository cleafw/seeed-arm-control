# 语音控制接入规划 — 分阶段实施与验收

> 工程：`seeed-arm-control`  
> 依据：`docs/通用机械臂方案规划.md` §5 / 阶段 5  
> 原则：**Voice 永不直连电机**；一律调 Core REST；弱算力可不部署 Voice。  
> 更新日期：2026-08-27（**V0～V6 已落地**）

部署操作见 [`语音部署说明.md`](语音部署说明.md)。

---

## 0. 当前基线（完工状态）

| 项 | 现状 |
|----|------|
| Core 录播 / 急停 / 跟随 / 校准 | REST + WS |
| Voice sidecar | `voice/`：health + listen + 可选 Whisper |
| 命名姿态 API | `/api/named_poses*` |
| `VOICE_ENABLED` / health / policy | `config.py` + `voice_settings.json` |
| UI 语音入口 / 策略 | `VoiceControlPanel`（启用 + 跟随/语音优先 + 文字试说） |

**总体验收目标：**

1. Pi / 不启用：无语音动作路径，跟随录播不受影响。  
2. Jetson / 启用：规则 NLU（文字或 ASR）→ 只通过 Core API 驱动机械臂。  
3. 策略：`follow_only` / `voice_in_follow` / `follow_first` / `voice_first`。  
4. 语音执行期间与主臂跟随不抢写电机（Core 单写者）。

---

## 1. 架构约定（各阶段共用）

```text
麦克风 / ASR / 规则 NLU / TTS          ← Voice 模块（可选进程/容器）
        │ 仅 HTTP
        ▼
   意图 Intent JSON  或  Core /api/voice/utterance
        │
        ▼
Core FastAPI（本仓库）            ← 唯一写电机入口
        │
        ▼
Leader / Follower Drivers
```

| 规则 | 说明 |
|------|------|
| 单写者 | 任意时刻只有 Core 控制线程写从臂 |
| 意图白名单 | Voice 只能发已登记意图；未知意图拒绝 |
| 能力探测 | `GET /api/voice/capability` |
| 部署形态 | `core` 与 `core+voice`（见部署说明 / compose profile） |

## 3. 第一期意图白名单

| Intent id | 中文示例 | Core 动作 |
|-----------|----------|-----------|
| `estop` | 急停 / 停下 | pause |
| `resume` | 解除锁定 / 继续跟随 | resume |
| `stop_play` | 停止播放 | stop_playback |
| `play_action` | 播放「挥手」 | play by name/id |
| `goto_pose` | 回到初始位 | named_pose goto |
| `free_move` | 自由拖动 | free_move |
| `set_policy` | 切换语音策略 | settings |

**第一期不做：** 开放域控臂、录制意图、视觉伺服。
