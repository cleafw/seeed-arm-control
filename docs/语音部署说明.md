# 语音控制部署说明（core / core+voice）

> 配套：[`语音控制接入规划.md`](语音控制接入规划.md)  
> 原则：Voice **只 HTTP 调 Core**，不挂串口 / CAN。

---

## 1. 仅 Core（Pi / 无算力）

不部署 Voice 进程，也不勾选页面「启用语音控制」。

```bash
# Docker 示例
docker compose -f deploy/docker-compose.yml up -d
```

环境变量可不设 `VOICE_*`（默认关闭）。UI 左侧语音区可保持未勾选；跟随 / 录播行为与改前一致。

---

## 2. Core + 文字语音闭环（推荐先上机）

无需 ASR 模型。启用后页面「试说一句」或 CLI 注入中文 → 规则 NLU → `/api/voice/utterance`。

```bash
# env 示例（见 deploy/rebot.env.example）
VOICE_ENABLED=1
# 不设 VOICE_HEALTH_URL 时：启用后即视为 reachable（文字闭环不依赖 sidecar）
VOICE_POLICY=follow_first
```

验收：

```bash
export REBOT_CORE_URL=http://127.0.0.1:1882
python -m voice.mock_inject --text 急停
python scripts/voice_acceptance.py
```

浏览器：勾选「启用语音控制」→ 输入「急停」或「停止播放」→ 发送。

---

## 3. Core + Voice sidecar（Jetson 设备麦克风，推荐）

上电自启、不依赖电脑浏览器麦克风。硬件：Seeed **ReSpeaker 4 Mic Array**。

```bash
# 在 Jetson 仓库根目录（需 sudo）
bash deploy/install_voice_jetson.sh
```

会安装：

- `vosk` + 中文小模型  
- systemd：**上电自启** `seeed-arm-control`（:1882）+ `seeed-arm-voice`（:1883，设备端听写）  
- env：`VOICE_DEVICE_LISTEN=1`、`VOICE_VOSK_MODEL=...`、`VOICE_HEALTH_URL=...`

```bash
# 查看是否已开机启用
systemctl is-enabled seeed-arm-control seeed-arm-voice
systemctl status seeed-arm-control seeed-arm-voice --no-pager
```

使用：上电后服务自动起来；页面勾选「启用语音控制」（安装脚本已默认打开）→ **对着设备 ReSpeaker 说「急停」「播放xxx」/动作名**。识别结果在左侧「识别调试」里刷新。

不要依赖电脑 `localhost:5173` 开麦；那只是开发调试用。

---

## 4. 策略说明

| 策略 | 行为 |
|------|------|
| `follow_first`（默认 UI） | 主臂近期运动可打断语音播放；主臂刚动时拒绝新 play/goto |
| `voice_first` | 语音 play/goto 打断跟随；执行中掰主臂不抢回 |
| `follow_only` | 仅允许急停等系统意图 |
| `voice_in_follow` | 允许语音动作，不因主臂运动拒绝（API 仍可用） |

设置写入 `recordings/voice_settings.json`，重启保留。

---

## 5. 回归清单

- [ ] 无语音：跟随 + 录制 + 回放正常  
- [ ] 启用后文字「急停」→ paused  
- [ ] 「解除锁定」→ resume（需校准就绪）  
- [ ] 「播放 &lt;已有动作名&gt;」→ playback  
- [ ] 跟随优先：播放中掰主臂 → 停止播放回跟随  
- [ ] 关掉 Voice sidecar（若配置了 health URL）→ Core 仍可用；UI 显示未连通  
- [ ] 重启后端口 / 臂型 / 语音勾选仍有效

## 6. Windows 本机 Whisper 路径示例

```text
VOICE_WHISPER_MODEL=F:\电脑文件\软件\AI工具\AI模型\Windows\asr\whisper-base
```

需自行安装 `transformers` + `torch`（或 `faster-whisper`）。未安装时仍可用文字 `/listen` 与 Core `/utterance`。
