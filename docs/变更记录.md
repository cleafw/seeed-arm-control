## H. 双臂串口探活与就地重连（2026-08-20）

**问题**

1. 串口 `SerialException` / `OSError` 会打断控制环并 `SIGTERM`，页面卡在「正在连接到机器人服务…」。
2. 主臂读失败被吞掉后沿用旧角度；`paused` 不读写硬件 → 关电源/拔 USB 后 UI 仍显示「正常」。

**修复**

- 控制环遇链路故障：**不退出进程**；标记 `arms` 状态，约 2s 周期重连。
- 主动探活（约 0.8s，连续 2 次失败才判定）：设备节点、`check_link`（主臂 ping / 从臂 CAN `_rx_gen`）。
- 主臂 `pipermate`：链路错误上抛；连续无新角度视为断电。
- 从臂 `Motor._rx_gen`：refresh 无反馈 → 异常。
- 打开串口后必须 `check_link` 通过才标 `ok`（避免「USB 在但电机没电」假正常）。
- 故障恢复后：`paused` + hint「请解除锁定进入跟随」（首次上电成功不强制 paused）。
- UI：底栏「机械臂状态」一窗双臂；顶部链路异常横幅。
